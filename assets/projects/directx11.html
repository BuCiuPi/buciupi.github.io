    • Learn to create and manage resources like buffers, shaders, and textures, and understand concepts such as depth buffers, render targets, and multi-sampling for antialiasing.
    • Explore how to efficiently manage GPU resources and use advanced techniques like deferred rendering, instancing, and hardware tessellation to create realistic graphics with high performance.
    • Use HLSL(High-Level Shading Language), where i can write custom shaders for real-time lighting, shadowing, post-processing effects, and other visual enhancements.
    • Understand how to optimize rendering for different hardware configurations, making my applications robust and scalable across various platforms.
